# Grabador de sonidos nocturnos (sonambulismo)
- Proyecto personal de aprendizaje. El usuario es principiante en Claude Code.
- Objetivo: PWA para iPhone que escucha el micro por la noche y graba solo cuando detecta sonido (el usuario habla dormido).
- Cada grabación incluye 1-2 segundos previos al sonido para no cortar el principio.
- Organización: noches (por fecha) y, dentro de cada noche, sonidos con hora, duración y reproductor.
- Pantalla casi negra y Wake Lock para que el móvil no se bloquee.
- Coste cero: sin servidores de pago. Datos en el móvil (IndexedDB).
- Tecnología: HTML, CSS y JavaScript simple, sin frameworks.
- Explica siempre en español y con palabras sencillas qué haces y por qué.
- Trabaja en pasos pequeños y espera mi aprobación antes de cambios grandes.
